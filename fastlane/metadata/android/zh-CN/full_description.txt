<i>Materialious</i> 是使用 material design 的 <a href='https://github.com/iv-org'>Invidious</a> 客户端。  .
它让你浏览并观看视频，管理播放列表和使用频道。

<b>特性：</b>
<ul>
  <li>支持 Invidious companion </li>
  <li>扩展的 Invidious API 集成</li>
  <li>如果 Invidious 未能加载视频，可用备选方式 YouTube.js 进行加载（桌面和安卓） </li>
  <li>支持 homelab 用户禁用证书验证</li>
  <li>在 Invidious 会话间同步观看进度</li>
  <li>一起看模式</li>
  <li>内置 Sponsorblock</li>
  <li>内置 Return YouTube dislikes</li>
  <li>内置 DeArrow (本地处理作为备选方式)</li>
  <li>无广告</li>
  <li>无跟踪</li>
  <li>浅色/深色主题</li>
  <li>自定义颜色主题</li>
  <li>集成 Invidious 订阅、观看历史和更多</li>
  <li>支持直播</li>
  <li>支持 Dash</li>
  <li>章节</li>
  <li>仅音频模式</li>
  <li>播放列表</li>
</ul>
